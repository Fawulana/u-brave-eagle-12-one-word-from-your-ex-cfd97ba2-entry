One word an ex would use to describe the entrant — the word is **roommate**: the romance died so quietly a lover got demoted to a chore-splitting housemate.

## Run it

```sh
python3 main.py
```

Writes exactly one word to `/output/entry.txt` (8 bytes, no trailing newline). Deterministic, offline, Python standard library only.
